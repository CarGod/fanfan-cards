# 翻翻词卡 — Logo 设计

## 1. 概念

```
┌───────────┬──┐
│           │ ╱│   ← 折角：翻的那一下，也是「掀开看背面」
│  ▬▬▬▬▬    │╱ │
│  ▬▬▬         │   ← 卡面上的两行：一行词，一行释义
│              │
└──────────────┘
```

标记只有**两个形状**：一张圆角卡片，和它被掀起的右上角。

| 元素 | 造型含义 | 产品含义 |
|---|---|---|
| 圆角卡片 | 一张词卡 | 知识的最小单位 |
| 折角 | 翻页 / 掀开 | 「翻」——产品名里的那个动作 |
| 卡面两条线 | 一行词、一行释义 | 卡片上写着什么（32px 以下省去） |

折角同时装下三件事：**翻的动作、卡片的物性、掀开就看见答案的隐喻**。三重语义，两个色块。

### 为什么不是这些方向

评审过五个方向，其余四个各自输在一处：

| 方案 | 否决理由 |
|---|---|
| **卡扇**（三张卡摊成扇形） | 概念好，且与 fan 的英文语义呼应；但 16px 下三层叠压互相吃边，识别度明显低于翻角。降级为官网与商店大图使用。 |
| **被点亮的词**（一行文字中一段被高亮） | 最贴近产品第一秒发生的事，但更像标注 / 高亮工具，丢掉了「卡片与记忆」这一半。 |
| **双面卡**（定格在翻转中途） | 语义准确（闪卡就是两面），但 16px 下会被读成「两个方块」，需要品牌教育成本。 |
| **羽**（取「翻」的羽字旁） | 文化根性最强，但纯笔画无容器，16px 下两条弧粘连；对非中文用户是纯装饰。 |

也一并排除了翻译类产品的三件套：**地球、双向箭头、A→文**。看到这个标记的人不应该以为
这是个词典。

## 2. 几何

64×64 画布。

```
卡片   M14 6 h27 l17 17 v27 a8 8 0 0 1-8 8 H14 a8 8 0 0 1-8-8 V14 a8 8 0 0 1 8-8 Z
折角   M41 6 L58 23 H41 Z
文字条 rect(14, 33, 24×5.5, r2.75) opacity .92
       rect(14, 44, 15×5.5, r2.75) opacity .5
```

卡片是「圆角矩形 ∩ 半平面 `x − y ≤ 35`」——右上角被 45° 直线切掉，切下来的那块以
更浅的橙画在卡内，就成了折角。**折角永远是 45°。**

## 3. 用色

| 元素 | 色值 | 说明 |
|---|---|---|
| 卡片 | `#FF6A3D` 焰橙 500 | 品牌色 |
| 折角 | `#FFC6AE` 焰橙 200 | 见下 |
| 文字条 | `#FFF0E6` 暖白 | 只在 32px 以上出现 |

**折角为什么不是白色。** 第一版用暖白 `#FFF0E6`，在白底上几乎等于背景，整个角读成
「被切掉」而不是「被翻起」——而折角是整个品牌概念。改成浅一档的橙之后，它在任何背景上
都成立，而且更符合物理：翻过来的是同一张卡的背面，不是一张白纸。

**单色版**不是「同样的形状涂成一个颜色」——填充色块会让折角无处可读。它变成描边形态：
卡片轮廓 + 折角的两条内边（`M41 7 v16 h16`）。用于印刷、水印、禁用态。

## 4. 16px 是设计约束，不是缩放结果

工具栏与 favicon 是这个标记出现最多的地方，所以**先在 16px 上验证，再考虑 128px 好不好看**。

三条由此而来的硬约束：

1. **元素上限就是两个形状。** 加第三个几何元素，16px 下必然并成一团。
2. **图标按尺寸分别光栅化，不缩放。** `scripts/generate-icons.mjs` 对每个尺寸逐像素
   求几何的有符号距离场。把 128px 缩到 16px 会让折角和文字条一起糊成灰边。
3. **卡片边界按尺寸吸附到整像素。** 设计稿的 6/64 边距在 16px 上落在 1.5px，
   每条边都跨两个像素，整个标记会渲染成一团软灰。先把卡片的框吸附到整像素，
   再从这个框按比例推导圆角、折角和文字条——形状不变，边缘干净。

抗锯齿带固定为 1 像素宽。更宽显软，更窄开始出锯齿。

文字条在 **24px 以下自动省去**，React 组件与图标脚本用的是同一个阈值。

## 5. 使用规范

**安全边距**：标记四周至少留出 25%（16px 图标即 4px）的空白。

**最小尺寸**：屏幕 16px，印刷 8mm。

**允许**
- 纯色背景上使用
- 单色化（一色印刷、水印、禁用态）
- 与文字锁定为横向组合：标记 + 半个标记宽的间距 + 文字标

**禁止**
- 改变折角的角度或比例（45°，永远）
- 加描边、投影、渐变叠加
- 拉伸、旋转
- 放在照片或花纹上——标记依赖干净的边界
- **用焰橙做描边版标记**：`#FF6A3D` 在白底只有 2.85:1，描边要用 `#E85426`

## 6. 文字标

中文用**翻翻词卡**，字重 Semibold，字距 `-0.01em`。

英文名尚未定案。视觉系统对此不敏感——标记的语义来自「翻开一张卡」这个动作本身，
无论最终英文名是什么都成立，因此标记可以先于命名投入使用。

## 7. 资源

| 文件 | 用途 |
|---|---|
| `public/logo-mark.svg` | 矢量标记，用于网站 / README / 商店素材 |
| `public/icons/icon-{16,32,48,128}.png` | Chrome 扩展图标与 favicon，由脚本生成 |
| `src/components/icons.tsx` → `BrandMark` | 界面内的 React 版本，含 `mono` 单色形态 |

图标**不作为二进制文件维护**：`npm run icons` 从代码重新生成。
把四个 PNG 签进仓库等于把品牌标识变成不可修改的黑盒，改一次颜色就要重新打开设计工具。
现在改一行常量即可，而且 diff 是可读的。
