# Local ASR runtime

AI listening is opt-in (`videoListeningEnabled`, defaults false for new and existing settings). Enabling the setting makes the explicit video button available; it never starts audio capture automatically. Turning it off stops the page capture/queues and background/offscreen model work.

Normal listening selects pinned `Xenova/whisper-base` q4f16 WebGPU (about 85 MB model data). Missing GPU/shader-f16 capability selects Tiny q8 CPU before downloading Base. A GPU-specific initialization failure terminates that worker and retries once in a fresh Tiny worker; network/model download failures do not cause a second model download. Device loss stops the session and asks for a new explicit start. A lightweight Tiny label/tooltip indicates fallback, using the existing controls' auto-hide behavior.

The dedicated worker uses up to four CPU threads only when cross-origin isolation and shared memory are available; otherwise it uses one. The extension manifest enables COOP/COEP without weakening script CSP. `asrConfig.ts` retains pinned CPU/GPU diagnostic profiles, but normal offscreen messages explicitly request the Base GPU profile. The first initialization locks its profile; create a new worker to change it. Audio collection uses at most three new seconds at 1×, retaining natural-pause early cuts.

The browser build pins ONNX Runtime Web and its paired Common package to 1.30.0. Vite aliases both browser dependencies together; the unrelated native Node dependency retains its own Common version. The build copies the matching `ort-wasm-simd-threaded.asyncify.mjs` and `.wasm` files and records their package versions in `wasm/runtime.json`. Do not replace only the WASM file or assume a newer runtime still loads the former JSEP filename. Validate the actual extension origin, CSP, model download, and dedicated worker thread count after changing this integration.

Whisper automatic language prediction uses the custom language/transcribe prefix in `whisperLanguage.ts`; omitting `language` in Transformers.js 3.8.1 alone defaults to English. Benchmarking must retain this prefix, fixed sample/reference data, 16 kHz audio, silence handling, and rolling context. Real-time throughput is measured against newly arriving audio (three seconds at 1×), not the overlapping nine-second window. Faster playback and early silence cuts require separate validation.
