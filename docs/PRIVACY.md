# 翻翻词卡隐私政策

生效日期：2026 年 8 月 26 日 · 最后更新：2026 年 9 月 9 日

翻翻词卡是一款本地优先的 Chrome 扩展。开发者不运营用于接收扩展用户数据的服务器，
不使用广告、分析或追踪服务，也不会出售用户数据。

## 扩展处理的数据

为了提供网页英语阅读、语境解释、词卡与复习功能，扩展会处理以下数据：

- **网页内容与浏览信息**：当用户主动划词、解释或翻译时，扩展会读取选中文字、附近句子或段落、
  页面标题和页面网址。整页或整段翻译功能会读取当前页面中可见的文本。
- **翻翻模式与收藏词高亮**：用户开启翻翻模式后，扩展会在本机扫描当前页面中可见的文本，
  并与保存在浏览器本地的词库进行匹配。匹配与高亮完全在本机完成，不会把页面内容发送给
  AI 服务商、开发者或任何第三方。
- **YouTube 视频字幕**：当用户在 YouTube 播放器上打开双语字幕功能时，扩展会读取当前视频的
  字幕轨列表与字幕文本。字幕文本从 `youtube.com` 的字幕接口取得，该请求在页面上下文中发出，
  因此会带上浏览器已有的 youtube.com Cookie——这与页面自己取字幕的方式相同，扩展不读取、
  不保存、也不传输这些 Cookie。为了让 YouTube 返回字幕内容，扩展需要拿到播放器为该次请求
  生成的一次性校验参数，做法是让播放器自己取一次字幕并从中读取该参数；这个参数只用于紧接着
  的那一次字幕请求，不保存，也不发送给开发者或任何第三方。
- **学习数据**：收藏的词、解释、来源句子与网址、复习记录、学习活动和用户设置。
- **身份验证信息**：用户自行填写的 AI 服务 API Key，以及在启用 GitHub 同步时填写的 GitHub Token。

上述数据保存在用户自己的浏览器 `chrome.storage.local` 中。配置恢复默认尝试浏览器自动同步，配置及密钥还会写入浏览器管理的 `chrome.storage.sync`；不支持时仅保存在本机。用户可切换为手动配置模式。开发者无法访问这些本地数据或用户的浏览器同步空间。

## 数据何时会发送给第三方

扩展提供以下传输方式（自定义本机开发地址除外，网络请求使用 HTTPS）：

1. 用户选择并配置 AI 模型后，选中文字、必要的上下文、页面标题和网址会直接发送给用户选择的
   服务商（Anthropic、OpenAI、DeepSeek、Google Gemini，或用户自行填写的兼容 API 地址），
   用于生成解释或翻译。AI 请求中的 API Key 发送给对应服务商；配置备份中的密钥传输见第 3、4 项。
   用户打开 YouTube 双语字幕后，当前视频的字幕文本与视频标题会以同样的方式发送给该服务商，
   用于生成译文。
2. 用户主动启用 GitHub 同步后，词卡、来源信息、复习记录和学习活动会发送到用户自己的 GitHub
   仓库；GitHub 请求中的 Token 发送给 GitHub API。配置恢复不会把设置或密钥提交到词卡仓库。
3. 自动配置同步将插件设置、AI API Key 和 GitHub Token 写入浏览器的同步空间。是否跨设备传输由浏览器登录状态与同步设置决定，由 Google、Microsoft 或相应浏览器服务提供商处理。扩展不增加独立口令，不提供应用层额外加密，且无法确认云端上传完成时间。
4. 用户可导出包含完整密钥的 JSON 配置文件，或授权插件读写所选目录中的 `FanFan Cards/config.json`。选择 iCloud Drive 目录时，Apple 系统服务负责后续同步，扩展只操作用户授权的本地文件。目录句柄仅保存在本机；新设备需重新选择目录，权限失效时需重新授权。

开发者不会通过中转服务器接收上述数据。第三方服务如何处理数据，由用户与该服务商之间的条款
和隐私政策约束。

## 数据保留与删除

本地数据会一直保留，直到用户在扩展中清空数据、移除扩展数据或卸载扩展。用户可以在设置页导出插件配置 JSON（包含密钥，不包含词卡与复习记录），
也可以清空缓存或全部词卡。词卡与复习记录通过用户自己的 GitHub 仓库同步恢复。同步到 GitHub 的数据由用户自己的 GitHub 仓库设置与操作决定，
用户可在 GitHub 中删除。配置文件由用户在所选目录中管理和删除；浏览器同步副本由浏览器账号与同步设置管理。切换为本机模式会停止本设备继续同步，不会删除其他设备或云端已有副本。

## 安全与最小权限

扩展不加载或执行远程代码。外部请求使用 HTTPS；仅本机开发地址允许 `http://localhost`。
自定义 API 地址的访问权限只在用户点击“测试连接”时按目标域名申请。

扩展在 `youtube.com` 上注入一段运行在页面上下文中的脚本。它只做三件事：读取播放器公开的
视频与字幕轨信息、记录上述一次性校验参数、代为发出取字幕的同源请求。该脚本不访问任何扩展
API，不读取页面上的其它数据，也不与开发者的任何服务器通信。

扩展对信息的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）：
The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy,
including the Limited Use requirements.
